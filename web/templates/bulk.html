Bulk item entry

One item per line. Extended format:

[qty]Name | category | rarity | weight_lb | value | description | key=value ...
  • value: denominated (2gp, 50sp, 1,000gp) or bare integer (copper)
  • key=value: weapon, armor, tool, mount/vehicle, container, or per-row override attributes
  • Unknown key-shaped segments (dmg=1d4) are errors; plain prose becomes description
  • class= = weapon sub-type (e.g. simple-melee); armor base-AC uses armor-class=
  • container=true/false = IsContainer flag; parent=BackpackName = destination container
